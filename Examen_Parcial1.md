# Examen primer parcial

## Desarollo movil
En este proyecto abordaré el área de la programación relacionada a el desarrollo movil la cual nos ayuda a desarrollar aplicaciones para Android o iOS. Las 5 tecnologias relacionadas al desarrollo movil son:

# 1. React Native
![Logo de React Native](https://upload.wikimedia.org/wikipedia/commons/a/a7/React-icon.svg)

### Uso principal
React Native fue desarrollada por Meta y nos permite crear aplicaciones móviles para Android y iOS. Utiliza JavaScript y React.
### Vacante real o compañia que lo utilizan
Algunas empresas que lo utilizan son:
 
 1. Shopify usa React Native para el desarrollo de sus productos móviles 
 
 2. Coinbase utilizó en su momento React Native para renovar su estrategia de desarrollo móvil.
 3. Meta lo usa al ser su empresa creadora.
### Enlace de referencia
([Sitio oficial de React Native](https://reactnative.dev/))

# 2. Flutter
![Logo de Flutter](https://upload.wikimedia.org/wikipedia/commons/1/17/Google-flutter-logo.png)

### Uso principal
Flutter es un framework que utiliza principalmente Dart como lenguaje de programación, fue desarrollado por Google y nos permite crear aplicaiones  para Android, iOS, web o computadora.
### Vacante real o compañia que lo utilizan
Algunas empresas que lo utilizan son:
 
 1. eBay lo usan para compartir codigo entre iOS y Android. 
 
 2. Google la utiliza para la mayoria de sus aplicaciones como Google Pay, Google Ads, Google Classroom y Google Earth.
### Enlace de referencia
([Sitio oficial de Flutter](https://flutter.dev/))

# 3. Kotlin Multiplatform
![Logo de Kotlin Multiplatform](https://upload.wikimedia.org/wikipedia/commons/7/74/Kotlin_Icon.png)

### Uso principal
Kotlin Multiplatform nos ayuda a compartir código entre otras plataformas, utiliza el lenguaje Kotlin y nos permite desarrollar aplicaciones reduciendo la cantidad de código necesaria para escribir cada plataforma.
### Vacante real o compañia que lo utilizan
Algunas empresas que lo utilizan son:
 
 1. McDonald's usa Kotlin Multiplatform en su aplicación movil.
 
 2. Netflix lo utliza para compartir lógica en aplicaciones fuera de su área de producción movil.
 3. Duolingo lo usa para acelerar el desarrollo en sus plataformaas moviles.

### Enlace de referencia
([Sitio oficial de Kotlin Multiplatform](https://kotlinlang.org/multiplatform/))

# 4. Swift
![Logo de Swift](https://upload.wikimedia.org/wikipedia/commons/9/9d/Swift_logo.svg)

### Uso principal
Swift es un lenguaje de programación creado por Apple para desarrollar aplicaciones en sus dispositivos.
### Vacante real o compañia que lo utilizan
Algunas empresas que lo utilizan son:
 1. LinkedIn lo usa para desarrollar sus aplicaciones en el ecosistema de Apple
 2. VSCO utilizó Swift para crear una versión de su aplicación en fotografía.

### Enlace de referencia
([Sitio oficial de Swift](https://www.swift.org/))

# 5. .NET MAUI
![Logo de .NET MAUI](https://raw.githubusercontent.com/dotnet/brand/main/logo/dotnet-logo.svg)

### Uso principal
.NET MAUI fue desarrollado por Microsoft y es un framework que nos permite crear aplicaciones para Android, iOS o Windows usando C# como su principal lenguaje.
### Vacante real o compañia que lo utilizan
Algunas empresas que lo utilizan son:
 1. Fidelity usa este framework para desarrollar su plataforma de sistemas financieros
 2. NBC Sports Next usa .NET MAUI para desarrollar su aplicación SportsEngine
 3. Irth lo usa para modernizar su app movil.

### Enlace de referencia
([Sitio oficial de .NET MAUI](https://dotnet.microsoft.com/es-es/apps/maui))
